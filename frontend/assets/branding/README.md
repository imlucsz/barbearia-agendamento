# Marca da instalação

Coloque aqui os arquivos de logo próprios desta instalação. Use PNG, JPEG, WebP ou AVIF, sem conteúdo ativo; configure `brand.logoUrl` em `../js/installation-config.mjs` com um caminho `../assets/branding/nome-do-arquivo.webp`. O gerador de instalação exclui os arquivos desta pasta para nunca copiar a marca de outra barbearia.
